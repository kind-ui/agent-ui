Ship an `agent-ui` skill for coding agents that build with Agent UI. Install it with `npx skills add kind-ui/agent-ui --skill agent-ui`, or read it from the package at `node_modules/@kind-ui/agent-ui/skills/agent-ui/SKILL.md`. It covers choosing from all 56 components, installing them in each framework layer, composing a chat, tool approvals and the sidebar shell, mapping AI SDK messages, exposing actions to agents, asking the person before risky actions, and theming. The registry's setup `AGENTS.md`, the README and Get Started now point at it.
