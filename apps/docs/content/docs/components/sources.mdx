## Composition

```text
Sources
├── SourcesTrigger
└── SourcesContent
    └── SourcesList
        └── SourcesItem
            ├── SourcesLink
            │   ├── SourcesIcon
            │   ├── SourcesTitle
            │   └── SourcesHost
            └── SourcesSnippet
```

`SourcesTrigger` is a native button that shows the `label`, else "Used N sources", and shows or hides `SourcesContent`. `SourcesList` renders a `SourcesItem` for each source, keyed by its `id`. `SourcesLink` links to the source's `url` and opens it in a new tab. `SourcesIcon` shows the source's `favicon`, or a link glyph until the image loads or without one. `SourcesTitle` shows the `title`, up to two lines, `SourcesHost` the host name without `www.`, which narrows first when space runs short, and `SourcesSnippet` the `snippet`, up to two lines. To arrange the parts yourself, pass them as children of `Sources`.

## Usage

### Sources

Pass `sources`, each with an `id` and a `title`, and optionally a `url`, `favicon` and `snippet`. Links accept `http`, `https`, `mailto` and relative URLs. A source with any other URL, like `javascript:`, shows as text with no link and no host name.

```tsx
<Sources
  sources={[
    { id: "limits", title: "Rate limits for the REST API", url: "https://docs.github.com/en/rest" },
    { id: "notes", title: "Meeting notes" },
  ]}
/>
```

### Streaming Sources

Add sources as the agent finds them, keeping each `id`. A source added to the open list after it first renders fades up once, and the count in the trigger updates without moving anything around it. A source whose title or URL changes updates in place, without fading in again. At full motion the list slides open; under `prefers-reduced-motion`, or with `motion="reduced"`, it fades in over 120 ms, and with `motion="none"` it shows at once.

### Opening

The list starts closed. Pass `defaultOpen` to start with it shown, or `open` with `onOpenChange` to control it; `onOpenChange` gets `"trigger-press"`, `"find-in-page"` or `"imperative"`. The list stays in the page while it's closed, so the browser's find in page reaches it and opens it.

### Agent

An agent connected with `createAgent` finds the sources by the trigger's text and reads `open`. `expand()` is offered while the list is hidden and `collapse()` while it shows. Like any component with a button, it also has UI SDK's generic `press`.
