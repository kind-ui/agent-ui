Use reasoning effort beside a [Model Selector](./model-selector.mdx) when the model can trade speed for more thinking. It's a row of levels, Low, Medium and High by default, with a mark that slides to the chosen one.

## Composition

```text
ReasoningEffort
├── ReasoningEffortIndicator
└── ReasoningEffortItem
```

`ReasoningEffort` is a group named by its `label` that holds UI SDK's Segmented Control, a radio group with one Tab stop. `ReasoningEffortIndicator` is the mark behind the chosen level, and each `ReasoningEffortItem` is a level.

## Usage

### Levels

Pass `levels` to name your own, each with the `value` the host receives and the `label` a person reads, from least to most effort.

```tsx
<ReasoningEffort
  levels={[
    { value: "minimal", label: "Minimal" },
    { value: "low", label: "Low" },
    { value: "high", label: "High" },
  ]}
  defaultValue="low"
  onValueChange={(effort) => setEffort(effort)}
/>
```

Pass `value` and `onValueChange` to control the chosen level, or `defaultValue` to start with one. `onValueChange` gets the level's `value`, with the reason `input-change` when a person chose it, or `imperative` from `setValue`. Pass `disabled` while the model can't change its effort.

### Keyboard

Tab moves to the chosen level. The arrow keys move to the next or previous level and choose it, and Space chooses the focused one.

### Motion

The mark slides to the chosen level. Under `prefers-reduced-motion`, or with `motion="reduced"`, it doesn't move: the chosen level fills in over 120 ms. With `motion="none"`, it changes at once.

### Agent

An agent connected with `createAgent` finds the control by its label and reads the chosen level. Its `setValue` takes a level's `value` or its label, the same as a person choosing it, and refuses a level that isn't listed. It needs no person to confirm.
