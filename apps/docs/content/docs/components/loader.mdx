## Installation

```bash tab="React"
npx shadcn@latest add @kind-ui/loader
```

```bash tab="Web Components"
npx shadcn@latest add @kind-ui/loader-web
```

## Usage

### Label

Pass `label` to say what's loading. It shows beside the dots and names the loader, "Loading…" by default. The loader is a polite status, so screen readers read a new label when it changes. The dots are hidden from them.

### Motion

The dots flow one after another. Under `prefers-reduced-motion`, or with `motion="reduced"` or `"none"`, they hold still. The loader takes no focus and has no keys.

### Agent

An agent connected with `createAgent` sees the loader as a status named by its label. It has no actions of its own.

<Caption>
  Runs in React and Web Components. On `<kind-loader>`, `label` and `motion` are attributes of the same name, and the element fills in its label and dots when it has no children.
