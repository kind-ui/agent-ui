## Usage

### Wrapping and Line Numbers

Long lines scroll sideways, fading at the edge where more is, until someone presses the wrap button, which reports its state with `aria-pressed`. Wrapped lines continue 2ch in from where they start. Pass `defaultWrap` to start wrapped, or `wrap` with `onWrapChange` to control it. Pass `lineNumbers` to number each line.

### Copying

The copy button copies the code and turns into a check for two seconds. It tells screen readers "Copied", or "Copy failed" when the browser refuses the clipboard write.

### Without the Header

Pass `header={false}` to leave out the language, the wrap button and the copy button, when the code sits under your own controls. On `<kind-code-block>`, add the `headerless` attribute instead.

### Highlighting

No highlighter ships with it. Pass `highlight`, a function that resolves the code as a list of tokens whose contents, joined, are the code. Each token can have a `color`, any CSS color, and a `fontStyle` of `italic` or `bold`:

```tsx
import type { Highlight } from "@kind-ui/agent-ui/core";

const purple = "light-dark(#7c3aed, #c4b5fd)";

const highlight: Highlight = async (code) =>
  code.split(/(\bawait\b)/).map((content) => (content === "await" ? { content, color: purple } : { content }));
```

Plain text shows until the tokens arrive. A `light-dark()` color follows the page's color scheme. The block asks for one result at a time, and doesn't ask again for code that failed until the code or the language changes.

### Streaming

Set `streaming` while the code is still arriving, and the view follows its end. Highlighting keeps up: the start that's already colored stays colored, and the new lines show plain until the next result.
