## Installation

```bash tab="React"
npx shadcn@latest add @kind-ui/thinking-indicator
```

```bash tab="Web Components"
npx shadcn@latest add @kind-ui/thinking-indicator-web
```

## Usage

### Label

Pass `label` to say what the agent is doing, like "Searching the docs". It shows before the dots and names the indicator, "Thinking" by default. The indicator is a polite status, so screen readers read a new label when it changes. The dots are hidden from them.

### Motion

The dots flow one after another; the label stays still. Under `prefers-reduced-motion`, or with `motion="reduced"` or `"none"`, the dots hold still too. The indicator takes no focus and has no keys.

### Agent

An agent connected with `createAgent` sees the thinking indicator as a status named by its label. It has no actions of its own.

<Caption>
  Runs in React and Web Components. On `<kind-thinking-indicator>`, `label` and `motion` are attributes of the same name, and the element fills in its label and dots when it has no children.
