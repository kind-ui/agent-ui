## Composition

```text
Action
├── ActionTrigger
│   ├── ActionIcon
│   └── ActionTitle
└── ActionContent
    ├── ActionQuote
    └── ActionResult
```

`Action` renders these parts when you pass no children; any children you pass replace them. The trigger is a native button that shows or hides the content. `ActionTitle` shows the `label`, `ActionQuote` renders `quote` as a block quote, and `ActionResult` renders `result` as [Markdown](./markdown.mdx). The quote and the result are left out while they're empty.

## Usage

### Quote and Result

Pass the action's name as `label`, the text it ran on as `quote`, and what it returned so far as `result`. Set `status` as the work moves along, as a [Step](./step.mdx) does.

```tsx
<Action label="Explain" quote={text} result={answer} status={isDone ? "complete" : "running"} />
```

While the status is `running`, the content stays open and `result` renders as streaming Markdown: each chunk parses only the blocks it changed. When the status turns `complete`, the content closes on its own, unless someone opened or closed it in the meantime. An action that goes straight from `pending` to `complete` stays closed.

### Announcements

When the action completes or fails, screen readers hear its title, like "Explain complete" or "Explain failed", once. The streamed result is quiet.

### Motion

The content grows open and shut. Under `prefers-reduced-motion`, or with `motion="reduced"`, it fades over 120 ms instead, and with `motion="none"` it changes at once.
