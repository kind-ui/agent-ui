## Usage

### Text

Pass the whole `text` so far on every update, not just the new part. When it extends the last text, only the added part fades in, and nothing before it moves. Any other text, like a shorter or regenerated reply, replaces it at once without fading. Pieces that have finished fading join into one, so the element stays small however long the text grows.

### Caret

Set `caret` while the text streams to show a caret after it, and turn it off when the reply ends. It holds still; nothing in the library loops but a spinner. The caret adds no width or line height, and screen readers skip it.

### Motion

New text fades in only at full motion. Under `prefers-reduced-motion`, or with `motion="reduced"` or `"none"`, it appears at once.

### Announcements

Streaming text is content, not a status: it has no role and announces nothing. If people need to hear progress, announce it from the container.

### Agent

An agent connected with `createAgent` sees streaming text by its kind, with no name, since it has no role. It has no actions of its own.

  Runs in React, Vue, Svelte, Solid and Web Components. On `<kind-streaming-text>`, `text` is a property or attribute, `caret` is a boolean attribute and `motion` an attribute of the same name.
