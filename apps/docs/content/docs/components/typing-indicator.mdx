## Installation

```bash tab="React"
npx shadcn@latest add @kind-ui/typing-indicator
```

```bash tab="Web Components"
npx shadcn@latest add @kind-ui/typing-indicator-web
```

## Usage

### Label

Pass `label` to say who's typing. It names the indicator, "Typing" by default, and stays hidden on screen. The indicator is a polite status, so screen readers read a new label when it changes. The dots are hidden from them.

### Motion

The dots flow one after another. Under `prefers-reduced-motion`, or with `motion="reduced"` or `"none"`, they hold still. The indicator takes no focus and has no keys.

### Agent

An agent connected with `createAgent` sees the typing indicator as a status named by its label. It has no actions of its own.
