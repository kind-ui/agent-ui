This run puts the human input components together the way a host app would. The agent asks a [Question](/docs/components/question), waits on a [Confirmation](/docs/components/confirmation) inside a [Tool](/docs/components/tool), and answers with [Feedback](/docs/components/feedback) and [Suggestions](/docs/components/suggestion) after it. A [Checkpoint](/docs/components/checkpoint) marks where the turn started, a [Notice](/docs/components/notice) and a [Guardrail Notice](/docs/components/guardrail-notice) explain what the agent may do, and the composer holds a [Model Selector](/docs/components/model-selector), [Reasoning Effort](/docs/components/reasoning-effort) and a [Context Meter](/docs/components/context-meter).

## What Happens

- **Question:** the run waits until you pick where the fix goes and press **Submit**. The form then reads "Answered" with your answer.
- **Approval:** the `deploy` tool shows "Run deploy?" with **Approve** and **Deny**. The first Approve leaves the request `submit-failed`, so the choices come back with "Decision not sent. Try again." The next one is recorded, and the tool keeps "Approved", not the buttons.
- **Checkpoint:** **Restore** opens a dialog that asks first. Once it's restored, the checkpoint reads "Restored".
- **Reply:** once the reply finishes, rate it with the thumbs. **Add a comment** then opens a box for a comment.
- **Suggestions:** each one sends a follow-up. "Email the logs to the vendor" is blocked, and the Guardrail Notice says why; press **Why?** for the policy, or dismiss it to pick again.
- **Composer:** pick a model and an effort level. The context meter fills as the run goes on; hover, focus or press it for the token counts.

Each component gets its state from the host as plain data, here a timer stepping through a script, and calls the host back when a person decides. In an app, the same data comes from your model's stream, for example through the [AI SDK adapter](/docs/adapters/ai-sdk).
