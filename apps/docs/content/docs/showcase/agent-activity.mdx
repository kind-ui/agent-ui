This run puts the step components together the way a host app would. The agent thinks with [Reasoning](../components/reasoning.mdx), calls two [Tools](../components/tool.mdx) at once, proposes a [Plan](../components/plan.mdx), hands the work to a [Subagent](../components/subagent.mdx) and keeps follow-up prompts in a [Queue](../components/queue.mdx). A [Status](../components/status.mdx) badge shows where the whole run stands.

## What Happens

- **Thinking:** Reasoning streams its text while `running`, then closes and reads "Thought for 6 s".
- **Tools:** both calls run side by side. `delete_branch` shows "Waiting for approval", and the run's badge reads "Needs input", until the host records the decision. The tool then keeps "Approved", not the request.
- **Plan:** the run stops on the plan until you press **Accept**. Its steps then tick off as the subagent finishes them.
- **Subagent:** its own tool calls nest inside it, and its result shows once it's done.
- **Queue:** the follow-ups wait their turn. Drag one to reorder it, or focus it and press Space to pick it up, the arrow keys to move it and Space to drop it. Delete removes it.

Each component gets its state from the host as plain data, here a timer stepping through a script. In an app, the same data comes from your model's stream, for example through the [AI SDK adapter](../adapters/ai-sdk.mdx).
