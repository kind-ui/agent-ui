## Stream the Answer from a Route

The chat posts its messages to `/api/chat`. Answer with the model's reply as a UI message stream. A model id like `"openai/gpt-5"` goes through the AI Gateway; any AI SDK provider's model works too.

```ts title="app/api/chat/route.ts"
import { convertToModelMessages, streamText, type UIMessage } from "ai";

export async function POST(request: Request) {
  const { messages }: { messages: UIMessage[] } = await request.json();
  const result = streamText({
    model: "openai/gpt-5",
    messages: await convertToModelMessages(messages),
    abortSignal: request.signal,
  });
  return result.toUIMessageStreamResponse();
}
```

It's a standard `Request` handler, so any server that takes one can serve it at that path.

## Render the Chat

The code in the example above is the whole chat. React uses `useChat`, Vue and Svelte the AI SDK's `Chat`, and Solid and Web Components build a `Chat` on the AI SDK's `AbstractChat`, since it ships no package for them. Each one then renders the same way:

- **Messages:** `fromUIMessages(messages, { status, error })` gives the last message the chat's status and error, and marks the earlier ones complete.
- **Rows:** each message is a `ConversationRow` with a stable `value` and its `index`, and `messageCount` says how many there are. The conversation follows new text while the reader is at the end, and **Jump to latest** brings them back once they scroll up.
- **Markdown:** each text part renders in a `Markdown` with `streaming` set while it arrives, so a half-written list, table or code block renders cleanly.
- **Sending and stopping:** `onSubmit` returns the promise `sendMessage` returns, so the composer stays pending until the answer ends, and Stop takes Send's place and calls `stop`.
- **Failures:** when the request fails, `MessageOutcome` shows the error with **Retry**, which calls `regenerate`.
