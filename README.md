# agent-ui

Agent-operable AI components for React and Web Components, built on [UI SDK](https://ui-sdk.dev/docs).

This repository builds and releases [`@kind-ui/agent-ui`](packages/agent-ui), its docs site, and its shadcn registry. It is under construction; see the [design spec](docs/superpowers/specs/2026-11-14-agent-ui-design.md).

## Develop

Requires Node 22.12 or newer and npm 11.9.

```bash
npm ci
npm run check:fast
```

See [AGENTS.md](AGENTS.md) for the scripts, layer rules, and the UI SDK docs to read before building a component, and [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.
